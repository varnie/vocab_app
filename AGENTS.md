# Working on vocab_app

Read [ARCHITECTURE.md](ARCHITECTURE.md) before any work on this project.
It records the current product direction, design decisions, and rules for changes.

- Preserve its boundaries and behavior when refactoring or adding features.
- Make the smallest clear change that solves the requested problem.
- Revisit a decision only for a concrete reason. Explain the consequences of changing
  it and respect authorization the user has already given.
- Update the relevant section of `ARCHITECTURE.md` when an agreed decision changes.
  Keep only current decisions and their rationale; do not retain superseded decisions
  or append a log of edits.
- Keep project Markdown documentation in English.

Explicit user instructions take priority. This file supplements general instructions.
